Bang Chan FENDI Monitor

A personal tool that checks retailer product pages for discounted FENDI sunglasses, maintains price history, and emails meaningful deal updates and monitor-health alerts to its owner.

The tool uses Google Gmail OAuth with the send-only permission. It does not request permission to read the inbox. Monitoring runs through a private GitHub Actions repository.

This is an independent personal project. It is not affiliated with or endorsed by FENDI, Bang Chan, Stray Kids, Google, or the retailers it checks. A product-family association is not a claim that a particular model was worn by Bang Chan.
