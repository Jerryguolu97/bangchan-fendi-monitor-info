Privacy policy

Effective 22 September 2026.

Bang Chan FENDI Monitor is a personal-use monitoring tool for the owner of the Google account that authorizes it.

Google account information

The app requests only the Gmail send permission to send deal notifications, health warnings, recovery notices, and setup test messages. It does not request inbox, contacts, calendar, or Google Drive access.

The operator configures sender and recipient addresses. OAuth client credentials and the refresh token are stored as encrypted GitHub Actions Secrets in the private monitoring repository. Google receives OAuth requests and outgoing email content; GitHub processes credentials and monitoring data to run the scheduled workflows. Credentials are not intentionally printed in workflow logs.

Other data and retention

The private repository stores public retailer product information, observed prices, verification timestamps, notification history, and operational errors. Git history retains prior committed versions. Diagnostic workflow artifacts are retained for 14 days. A local OAuth client configuration may be retained on the operator's computer for setup; the helper does not save refresh tokens to local files.

The app does not sell Google user data, use it for advertising, or use it to train AI models. Google user data is used only to provide the requested email notifications. Use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Control, deletion, and contact

The owner can revoke the app through Google Account connections, disable GitHub Actions schedules, and remove repository Secrets. Removing current files does not erase prior Git history or delivered emails; those must be managed separately. For questions or deletion, contact the owner of the Google account that authorized this personal app.

This informational website

These static pages have no application analytics, advertising, forms, or custom cookies. The hosting provider may process routine request information under its own privacy policy.
